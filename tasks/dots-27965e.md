tasks hides steps whose exclusive needs a session cannot meet when TASKS_WITHOUT names them (comma-separated; names a project does not declare are ignored). On the daily desktop the idle host is never available, so agent sessions started there should not be offered quiet-host captures; a TTY session with the desktop stopped should be. Export TASKS_WITHOUT=quiet from the graphical session environment (e.g. environment.d or the compositor's session env), not from the login shell, so TTY logins stay unset. Check that harness-launched agents inherit it. Source: tasks repo docs/specs/2026-10-03-lanes-needs-groups-design.md §4.3.
