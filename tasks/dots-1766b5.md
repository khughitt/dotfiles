Found on europa 2026-09-24. proto/projects/natural-systems had been moved from ~/d/natural-systems. Its .git/worktrees still recorded six Claude Code agent worktrees at the old path (/mnt/ssd/Dropbox/natural-systems/.claude/worktrees/agent-*), locked `claude agent agent-<id> (pid N)` by a process that no longer exists. work-link reported each as `unowned ... relock it on the host that owns it`, but no host owns them: the repository moved. The fix was `git worktree unlock` then `git worktree prune`.

Suggested: when the recorded path is under the scan root but not under the repository's current top level, report that the repository moved, and suggest unlock + prune instead of relocking. Claude Code agent locks (`claude agent agent-<id> (pid N)`) could also be recognised and named as such.
